Get started and learn how Personal Navigator works

Getting started

First create the folder %USERPROFILE%\Personal; the current version indexes that folder. Then install the Windows application and press Ctrl+Alt+Space.

What does the app search?

Names and paths under the Personal folder, with optional deeper file results, exclusions, approximate spellings and a built-in set of related terms. It does not analyze file contents with a hosted model.

Does it upload my files?

No search backend is required. The index is stored locally.
