Personal Navigator / About

Personal files should feel navigable

Purpose

Personal Navigator was created by Abhijay Panwar to replace repeated folder hunting with a fast visual route to the right project.

Local by design

The app indexes names and paths on the computer. It does not require an account, hosted search service, cloud database, or file uploads.

Open development

The .NET desktop app, NSIS installer, automated tests, release workflows, documentation, and website are published under the MIT License.

View the official repository

Platform support

Windows 10 and Windows 11 x64 are supported. The current WPF interface does not provide macOS or Linux builds.
