Personal Navigator / Features

Visual project navigation that stays on your computer

Project-first search

Results are grouped by project roots. Search matches names, paths, approximate spellings and a small built-in related-word vocabulary. It does not call an AI search API.

More detail when needed

Switch to detailed results to view matching files and subfolders. Open a result in File Explorer or navigate the visual map.

Windows integration

Open the map with Ctrl+Alt+Space. The installer also adds Start menu, Explorer context-menu and Send To integration.

Privacy

Indexing and search occur locally. Local preferences and the cache are stored under your user profile. No account is required.
