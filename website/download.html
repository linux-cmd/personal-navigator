Install in four steps

  1. Download the Windows setup executable above.
  2. Open it, review the MIT License, and choose the installation folder.
  3. Choose optional desktop and startup shortcuts, then select Install.
  4. Launch the app and press Ctrl+Alt+Space.

Safety and upgrades

Current builds are unsigned and Windows SmartScreen may warn. Verify the SHA-256 value above. Running a newer installer upgrades the existing installation while preserving settings. Uninstall through Windows Settings or the Start menu.
