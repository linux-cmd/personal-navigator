Latest version

Install in four steps

  1. Open the release and download the Windows setup EXE if available.
  2. Follow the wizard and install for your Windows account. Older releases require extracting the ZIP and running the included PowerShell script.
  3. Create %USERPROFILE%\Personal and put projects inside.
  4. Open the app and press Ctrl+Alt+Space.

Safety and upgrades

Current builds are unsigned and Windows SmartScreen may warn. Download only from official GitHub Releases. Updates are manual; rerun the setup wizard to upgrade. Uninstall through Windows Settings or the Start menu.
