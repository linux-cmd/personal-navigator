Personal Navigator / Roadmap

Priorities and open development work

Installer and release quality

Provide a conventional Windows setup wizard, repeatable release packaging, SHA-256 checksums and clean-machine upgrade verification.

First-run experience

Support choosing an index directory instead of requiring the current default Personal folder. Improve error handling for missing folders.

Maintenance and trust

Review code signing, app update notifications, documentation and accessibility.

Cross-platform exploration

The current WPF interface does not run on Linux or macOS. Supporting another platform requires a cross-platform UI design and testing.

These items are plans, not promises or shipped features. Track implementation through GitHub issues.
